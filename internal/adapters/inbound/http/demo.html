SocketFabric event demo

Paste a short-lived client token in each panel and connect. Both clients join the selected room after authentication. Publish an event from your terminal using the README curl example, then watch both clients receive it.

Keep the tokens scoped to the same project and room. Tokens stay in this page's memory. Reloading clears them. Network failures reconnect with backoff and authenticate again before restoring your selected subscriptions. An expired or rejected token stops retries until replaced; events sent while disconnected may be missed permanently.
